# @spudly/eslint-config

Shared ESLint 10 flat config for Spudly repos (Eciperay, Memorize, and the
design system). Composable named exports ported from Eciperay's
`eslint.config.ts`.

See the full README on the `feat/shared-eslint-config` branch / in the
published package for usage, the export inventory, and migration notes.
